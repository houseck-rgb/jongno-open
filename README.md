# 종로점 홀 오픈 체크리스트

사진 촬영, 촬영 시간 자동 기록, 완료 체크, 보고 내용 공유 기능이 포함된 모바일용 웹앱입니다.

## GitHub Pages 올리는 방법

1. GitHub에서 새 저장소를 만듭니다.
2. 이 폴더의 `index.html`과 `README.md`를 업로드합니다.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. **Deploy from a branch**를 선택합니다.
5. Branch는 **main**, 폴더는 **/(root)**를 선택하고 저장합니다.

몇 분 후 표시되는 주소로 앱을 사용할 수 있습니다.

## 사용 방법

- 분홍색 사진 버튼을 누르면 카메라가 열립니다.
- 촬영 후 사진과 시간이 자동으로 저장됩니다.
- 오른쪽 체크 버튼으로 각 업무를 완료 처리합니다.
- 하단의 **보고 내용 공유** 버튼으로 카카오톡 등에 보고 내용을 보낼 수 있습니다.
- 사진과 체크 기록은 사용하는 기기에만 저장됩니다.
